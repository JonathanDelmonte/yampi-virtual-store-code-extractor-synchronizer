Como editar no computador
  1. Extraia o ZIP em uma pasta fora do repositório da extensão e abra essa pasta no VS Code.
  2. Com Node 24 instalado, execute npm ci, npm run check e npm run dev.
  3. Edite os arquivos de tema/. Preserve .yampi-sync/ para conferir os originais.
  4. Volte à aba Importar projeto e escolha a pasta inteira do projeto.

O que a extensão encontra na pasta?
tema/
Textos e imagens do projeto que você editou.
.yampi-sync/
A referência original para comparar com o estado atual da loja.

Dependências, ferramentas, documentação e a prévia local ficam fora do envio. Você também pode escolher só tema/ se o original desta loja já estiver guardado na extensão.

Como funciona o envio?
  1. Escolha a pasta ou o ZIP e confira os arquivos comparados.
  2. Revise conflitos e selecione o que deseja enviar. A loja de destino aparece na confirmação.
  3. A extensão guarda e baixa o backup antes de gravar, e confere o conteúdo após recarregar o editor.
  4. Confira em Ver prévia na Yampi. Publicar continua sendo uma ação sua.

Criações e imagens usam os controles do editor, sem criar pastas. O envio para no primeiro erro e preserva o registro do que já foi feito.
